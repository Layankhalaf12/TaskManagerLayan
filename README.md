The assignment assisted me in relating security concepts with actual Spring boot code.
I got to know how to implement SecurityFilterChain to secure routes, to add in-memory users using bcrypt,
and implement role-based and ownership based access in service layer. Another reason I understood is why layered architecture is important:
the controllers remain thin, whereas service also includes the business logic and security measures.
The flow was made visible by constructing the UI with simple Thymeleaf views and the access rules were checked by using various accounts.
In general, I am more certain about the use of secure and role-conscious web applications.
